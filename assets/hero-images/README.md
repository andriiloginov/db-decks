# Hero images

Бібліотека готових hero-зображень (3D isometric icon, метал, білий/прозорий фон) для
`cover()` і `statement()`. Просте правило: кидаєш PNG у `images/`, додаєш один запис у
`manifest.json` — і зображення одразу доступне для вибору при генерації будь-якої
презентації.

## Як додати нове зображення

1. Поклади файл у `images/<id>.png`. Бажано: квадратне, обрізане по контенту, прозорий фон.
2. Додай запис у `manifest.json`:

```json
{
  "id": "<унікальний-slug>",
  "file": "images/<id>.png",
  "label": "Коротка людська назва (укр.)",
  "tags": ["ключові", "слова", "для пошуку"]
}
```

3. Закомить і запуш.

## Як цим користується скіл

При генерації деки, на кроці вибору hero-зображення для `cover()` / `statement()`:

1. Тягне `manifest.json` з `raw.githubusercontent.com` (публічний repo — жодних токенів не
   треба; для приватного repo знадобиться токен, який користувач налаштовує сам).
2. Показує список `label`-ів користувачу (або підбирає найбільш релевантний за `tags` під
   контент деки).
3. Качає обраний `images/<id>.png` за прямим raw-URL.
4. Використовує його як `hero: 'path.png'` — так само, як і файл, надісланий вручну.

Джерело зображень — окремий процес (ComfyUI-генерація + Figma-каталогізація), сюди
потрапляють вже готові, відібрані фінальні PNG.
